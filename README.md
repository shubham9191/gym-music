# GYM MUSIC — Clean Version

This version uses the supplied gym hero image and includes:
- Clean hero landing section
- Mini YouTube video player
- Play/Pause, Previous, Next
- Seek and volume
- Searchable playlist
- Your YouTube playlist ID already configured
- Responsive mobile layout

## Files
- index.html
- style.css
- app.js
- gym-hero.png

## Deploy
Upload all files to GitHub and connect the repository to Vercel.


## Audio-style mode
The interface is designed as an audio player and hides the video surface. Playback still uses YouTube's permitted embedded player underneath; it does not extract or re-host YouTube audio.
