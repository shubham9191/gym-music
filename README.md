# GYM MUSIC

A Vercel-ready single-page gym music player using the YouTube IFrame Player API.

## Your playlist

## Run locally
Just open `index.html` in a browser, or use any static server.

## Deploy to Vercel
1. Put `index.html`, `style.css`, and `app.js` in a GitHub repository.
2. Import the repository into Vercel.
3. Choose a static/other project with no build command.
4. Deploy.

## Important
The site uses YouTube's embedded player and does not download or re-host the playlist audio. Playback depends on YouTube and whether each video permits embedding.
